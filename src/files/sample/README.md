# Night Sky

A small sample project, here so you can see how Nebula works before you start your own. Explore it, change anything, and delete it whenever you like.

- **Guides** holds three notes: an [[Observing plan]] with a checklist, a page on [[Orion]], and one on the [[Moon phases]].
- **Sketches** holds a canvas, [[Winter hexagon.excalidraw|Winter hexagon]]: an Excalidraw drawing you can edit.
- **Photos** holds an image, and **Charts** a PDF star chart.

Start with the [[Observing plan]], then the charts.

Every file here is a real file. Rename it, move it, or download the whole project as a .zip.
