# Image conversion

**Agent:** Claude Code · **Repo:** ss-nebula · **Asked for:** "change format to webp and maybe change image resolution"

## Done
- Right-click an image for **Convert image…**, or a folder for **Convert images…**
- WebP at 80% by default; JPEG and PNG too
- Never upscales, and skips a result that would be larger
- Keeps the original unless you choose *Replace*
